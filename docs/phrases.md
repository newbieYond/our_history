# 홋카이도 여행 회화

2026-10-07 추가. `#/hokkaido/phrases`에서 일본어·한국어 해석·한글 독음을 함께 볼 수 있습니다. 상황 태그를 다시 누르면 전체로 돌아가며 상황·날짜·검색을 함께 적용할 수 있습니다. 일본어 복사 버튼은 원문만 복사합니다.

표현 150개는 기존 7일 일정에 맞춰 작성했습니다. 공항·JR, 호텔·조잔케이 송영버스, 료칸 온천, 식당·시메파르페·주조장, 쇼핑·면세, 비에이 투어·모이와야마, 택시·시전, 기본 표현, 편의점·일상, 길 안내·분실의 10개 상황을 다룹니다. 식당의 세부 주문 요청, 객실 난방·추가 침구, 짐 보관·열차 지연 확인, 선물 보냉·포장, 분실물 문의까지 포함합니다. 확정되지 않은 비에이 투어의 예약 확인 표현에는 예약 완료 후 사용하는 문장임을 표시했습니다. 가격·운행 시간·면세 조건을 새로 확정하지 않고 현장에서 질문할 수 있도록 구성했습니다.

기본 표현과 교통·쇼핑 상황은 [국제교류기금 이로도리 입문](https://www.irodori.jpf.go.jp/starter/pdf.html)의 상황 구성과 대조했습니다. 지명 표기는 [JR 홋카이도](https://www.jrhokkaido.co.jp/airport/index.html), [조잔케이 관광협회](https://jozankei.jp/about/)를 참고했습니다. 교재를 전재하지 않고 여행 일정에 맞는 문장을 작성했습니다. 한글 독음은 근사치이며 장음은 `-`로 표시합니다.

공통 `PhrasebookScreen`과 `Phrasebook` 타입을 사용하며 데이터는 `src/trips/hokkaido/phrases.json`에 둡니다. 회화 데이터가 있는 여행만 메뉴가 나타나므로 다른 여행에도 언어·표현 데이터를 추가할 수 있습니다.
