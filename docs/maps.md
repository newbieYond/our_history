# 여행 지도

2026-10-07부터 제주·홋카이도는 공통 `TravelMap`의 실제 위경도 지도를 사용합니다. 배경은 OpenStreetMap, 조작은 Leaflet 1.9.4, 겹친 장소는 Markercluster 1.5.3입니다. 여행 테마와 표지·일정 이미지는 유지합니다.

저장 장소 화면에서 검색·권역·종류 태그가 지도와 목록에 동시에 적용됩니다. 지도 이동으로 장소 목록이 사라지지 않습니다. 날짜별 지도는 해당 날짜의 장소와 예비 스위치를 따르며, 일정·장소 카드에서 선택하면 지도 마커와 아래 상세가 연결됩니다. 숫자 묶음을 클릭하면 확대되고 최대 확대에서 동일 위치 장소는 펼쳐집니다. 전체 보기는 현재 조건의 모든 장소가 들어오도록 시야를 맞춥니다. 방향키 이동, +/− 확대, Enter로 마커·묶음 선택을 지원합니다.

## 위치 자료

여행별 `coordinates.json`에 201곳(홋카이도 68, 제주 133)의 위경도, 출처 URL, 장소명·주소, 확인일을 기록했습니다. 기존 Google 지도 링크의 장소 ID로 위치를 대조했으며, 일부 무효 ID는 이름·주소로 확인했습니다. 좌표를 얻지 못한 장소가 추가되더라도 목록은 유지되고 지도에 위치 미등록 수가 표시됩니다.

원본 `places.json`, `days.json`은 보존했습니다. 다음 차이는 정규화 단계 또는 안내 메모에 반영합니다.

- 홋카이도 도산코 플라자의 기존 링크는 일반 PLAZA 매장을 가리켜, 같은 이름·삿포로 지점을 대조한 좌표와 링크로 수정했습니다.
- 제주 산방식당의 기존 링크는 제주시 지점이었으나 기존 주소·좌표·DAY 5 동선은 모슬포 본점입니다. [제주관광공사 본점 안내](https://visitjeju.net/en/detail/view?contentsid=CONT_000000000501267)와 주소를 대조해 본점 좌표와 링크로 수정했습니다.
- 빙설의문은 기존 권역은 신치토세이나 저장 링크는 삿포로 매장, 누벨바그 르타오는 오타루 본점입니다. 방문 날짜를 유지하면서 실제 지도 권역과 확인 메모를 분리했습니다.
- 은하폭포는 소운쿄에 있어 별도 권역으로 표시합니다. 비에이·후라노의 예비 계획 상태는 유지합니다.
- 픽업카페 행원점은 원본 링크가 바로 옆 카멜커피와 동일합니다. 링크 위치를 표시하되 정확한 행원점 위치 확인 메모를 붙였습니다. 이름 검색으로 나온 제주시 다른 지점으로 바꾸지 않았습니다.
- 미확정 감귤 농장은 저장 후보 위치를, 스마일 로드는 링크에 있는 공항 대표 위치를 표시하고 확인 메모를 붙였습니다.
- 신치토세 공항은 도착일과 귀국일 모두에 표시하도록 `[1, 7]`로 연결했습니다.

## 조작과 배경 지도

기존 일러스트 지도는 확대 전 드래그 제한과 스크롤 중심 휠 조작을 직접 구현했습니다. 현재는 [Leaflet 기본 조작](https://leaflet.github.io/Leafdoc/Leaflet-docs.html)을 사용해 처음부터 드래그, 커서 위치 휠 확대, 더블클릭 확대, 두 손가락 확대를 제공합니다. 상세는 지도를 가리지 않게 아래에 표시합니다. 실제 도로 경로는 임의로 그리지 않고 Google 지도 길 찾기 링크를 제공합니다.

[OpenStreetMap 타일 정책](https://operations.osmfoundation.org/policies/tiles/)에 맞춰 표준 HTTPS 타일 URL과 보이는 저작자 표시를 사용합니다. 브라우저 기본 캐시를 사용하며 타일 사전 다운로드·오프라인 저장은 하지 않습니다. 배경 지도 오류 시 안내를 표시하고 장소 목록과 외부 지도 링크는 유지합니다.
