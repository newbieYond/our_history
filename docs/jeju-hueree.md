# 제주 휴애리 추가

확인일: 2026-10-24. 사용자 제공 [Google 지도 링크](https://maps.app.goo.gl/Fx5Z2ULPT23W88jo9)는 **휴애리 자연생활공원**, 제주특별자치도 서귀포시 남원읍 신례동로 256을 가리킵니다.

## 일정과 의견

- 11월 4일(DAY 6) 오전의 감귤 따기 시간을 휴애리 방문으로 구체화했습니다. 감귤체험·핑크뮬리 산책·동물 구경을 한 곳에서 즐기는 계획이며 점심 이후의 기존 일정은 유지합니다.
- 사용자와 동행인이 모두 동의한 장소로 추가하되 체험 예약은 미확정입니다. 감귤 생육과 현장 상황, 꽃 상태에 따라 가능한 활동을 방문 전에 확인하도록 적었습니다. 기존 30~60분은 농장 체험만의 예상이므로 공원 전체 방문에 그대로 적용하지 않습니다. 확정되지 않은 방문 시각·체류 시간·요금은 추가하지 않았습니다.
- 기존 미정 ‘감귤 체험농장’(ID 30)은 날짜 배정을 해제하고 예비 후보로 보관합니다. 기존 지도 URL·좌표·평가·의견·미정 설명은 유지합니다. 휴애리는 별도 ID 144로 추가해 기존 농장의 평점을 옮기지 않았습니다.
- 성호 의견에는 감귤체험·핑크뮬리·동물 구경이 여행 계획에 잘 맞는다는 취지를, 세인 의견에는 전적으로 동의하며 좋은 리뷰와 도민 명소라는 소개를 마음에 들어 했다는 사용자 전달 내용을 반영했습니다. ‘도민 명소’와 리뷰 평가는 동행인의 의견이며 별도로 검증한 공적 사실로 표시하지 않습니다. 두 사람의 숫자 평점은 미평가로 둡니다.
