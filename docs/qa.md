# 통합 검증 기록

검증일: 2026-10-07. Node.js 24.5.0 / pnpm 10.32.1 / Chrome에서 확인했습니다. CI는 Node.js 22를 사용합니다.

- `pnpm test`: 5개 회귀 테스트 통과. 여행·날짜 URL, 평점의 null/0 처리, 원본 장소 수·ID·링크·이미지, 다중 날짜 장소와 최신 EV4 예약 메모, 여행별 저장소·손상/차단 처리를 확인했습니다.
- `pnpm build`: 엄격한 TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 데스크톱 1440px와 모바일 390px에서 총 20개 화면 검증. 여행 선택, 두 여행 홈·일정·장소, 여행 노트, 홋카이도 쇼핑·체크리스트에 가로 넘침과 깨진 이미지가 없었습니다.
- 제주 7일 모두 약도 마커 표시, 확대/초기화, 포인터 드래그, 예비 후보 숨기기, 일정 선택에 따른 지도 상세 연동 확인.
- 제주 전체 지도 목록 펼치기, 장소 검색과 검색 결과 없음 상태 확인.
- 홋카이도 상세 팝업의 Escape 닫기 및 초점 복귀 확인.
- 체크리스트 새로고침 후 유지, 여행 전환, 날짜 링크·뒤로 가기, 잘못된 여행 경로와 범위 밖 날짜의 안전한 처리 확인.
- 실제 임시 여행 폴더 생성 후 기존 라우터 변경 없이 자동 등록과 빌드 성공 확인. 검증용 여행은 삭제했습니다. 기존 여행 ID로 생성 요청 시 덮어쓰기를 거부하는 것도 확인했습니다.
- 브라우저 검증 중 JavaScript 실행 오류가 없었습니다.

지도 드래그 검증 과정에서 약도 이미지의 기본 HTML 드래그가 포인터 이벤트를 끊는 문제를 발견해 `draggable={false}`와 이미지 드래그 방지 스타일로 수정한 뒤 재검증했습니다.

화면의 여행 정보는 원본에서 가져온 내용이며 이번 통합에서 운영시간·운항·행사 등 정보를 새로 조사하거나 확정하지 않았습니다.

## 실제 지도 전환 검증 (2026-10-07)

기존 약도 조작 검증은 이전 버전의 기록입니다. 현재 지도는 Leaflet 기반입니다.

- `pnpm test` 7개 통과: 기존 보존 검증에 전체 201곳 좌표·출처·확인일·지점 대조, 지도/목록 공통 필터와 유효 좌표 검증 추가.
- Chrome 320px·390px·1440px에서 두 여행의 날짜별 지도 14개씩 총 42개 화면 확인. 7개 날짜 선택, 예비 스위치와 표시 수, 가로 넘침 확인.
- 두 여행 전체 및 12개 권역에서 태그·장소 목록·지도 표시 수 일치 확인. 검색 결과 없음과 선택 해제 확인.
- 실제 배경 지도 렌더링, 초기 상태 드래그, 휠 확대, 두 손가락 핀치, 방향키 이동, 숫자 묶음 Enter 확대, 마커 선택, 전체 보기 복원 확인. 지도를 이동해도 목록 수 유지.
- 일정 항목·장소 카드 선택에 따른 마커·아래 상세 연결, 상세 모달 Escape 닫기 확인. 상세가 지도 캔버스를 덮지 않음.
- 배경 타일 요청을 차단한 상태에서 오류 안내 및 68곳 목록·상세 사용 가능 확인. JavaScript 실행 오류 없음.
- 실제 배경 화면 검증 후 나머지 크기별 반복 검증에는 타일 요청을 대체해 외부 타일 다운로드를 줄였습니다.
